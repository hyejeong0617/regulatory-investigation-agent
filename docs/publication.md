# Publication provenance

This repository is a publication copy of the independently Codex-built v1 workspace.
Runtime code, tests, legal HTML, original questions, and selected raw evaluation
outputs are unchanged. Documentation was reorganized and written in English;
GitHub-facing reports use relative links. Offline CI was added. No inference,
retrieval, parsing, prompting, review, or answer-generation logic was changed.

Historical manifests retain original paths and hashes. The historical source-tree
hash describes the pre-publication workspace, not the new README or documentation
layout. `publication_manifest.json` records the runtime/data/raw hashes for this
copy. The original frozen archive is staged separately as a release asset.

The live SQLite budget ledger stays in the original local workspace and is never
published. Budget JSON snapshots document historical accounting only. `.env`,
virtual environments, caches and temporary files are excluded. API keys are not
part of this repository. Historical documents may refer to earlier paused stages;
the root README and v1 evaluation report describe the final evaluation outcome.

The package metadata retains the original distribution name `regulatory-investigator`;
the GitHub repository is named `regulatory-investigation-agent`. License selection
is left to the repository owner; no permissive license was added automatically.
